# Privacy policy for Downloads Stack

Downloads Stack does not collect, transmit, sell, or share personal information, telemetry, analytics,
or advertising identifiers.

The application reads file names, paths, timestamps, icons, and thumbnails from the folders that the user
chooses. This information is used only on the user's device to display and maintain the recent-files list.
The application does not upload those files or their metadata.

Settings, the local file index, and diagnostic error logs are stored only on the user's device under
`%LOCALAPPDATA%\DownloadsStack`. They can be removed by deleting that folder after closing the application.

Downloads Stack does not make network requests. Microsoft Store may independently process installation,
update, and diagnostic information under Microsoft's own privacy terms.

Questions about this policy can be submitted through the project's public issue tracker:
https://github.com/Vivoxti/Downloads-Stack-For-Windows-Tray/issues
